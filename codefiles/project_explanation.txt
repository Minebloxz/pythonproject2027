PART 1: OVERVIEW & HIGH-LEVEL EXPLANATION
--------------------------------------------------------------------------------

What is this program?
---------------------
This application is a visual, interactive calculus tool built in Python. It allows 
users to calculate both indefinite integrals (symbolic antiderivatives) and 
definite integrals (the area under a curve between two points, including infinite 
limits). It displays a high-resolution graph showing the function and the area or 
antiderivative.

How does it work under the hood? (The 3 Main Engines)
-----------------------------------------------------
Think of this application as three connected engines working together:

1. THE BRAIN (SymPy):
   - SymPy is Python's symbolic mathematics engine. Unlike basic calculators 
     that only process numbers, SymPy understands mathematical symbols like 'x'. 
   - It performs actual calculus rules (power rule, substitution, integration by 
     parts, trigonometric transformations, etc.) to calculate algebraic 
     antiderivatives, and computes exact numerical areas.

2. THE VISUALIZER (Pygame):
   - Pygame is a graphic and event library used here to build the user interface (UI).
   - It creates the application window, draws buttons, renders live text, 
     captures mouse clicks and keyboard presses, and draws custom grid axes and 
     curves pixel by pixel.

3. THE NUMERICAL TRANSLATOR (NumPy):
   - Computers cannot directly plot an abstract math formula; they require 
     concrete screen pixel coordinates.
   - NumPy converts mathematical formulas from SymPy into arrays of hundreds 
     of numerical data points along the x-axis, allowing Pygame to draw smooth 
     curves and shaded area regions.

class Button:
    def __init__(self, x, y, w, h, text, action_value, bg=BTN_BG, hover_bg=BTN_HOVER):
        self.rect = pygame.Rect(x, y, w, h)
        self.text = text
        self.action_value = action_value
        self.bg = bg
        self.hover_bg = hover_bg

    def draw(self, surface):
        mouse_pos = pygame.mouse.get_pos()
        is_hovered = self.rect.collidepoint(mouse_pos)
        current_bg = self.hover_bg if is_hovered else self.bg
        pygame.draw.rect(surface, current_bg, self.rect, border_radius=8)
        ...

    def is_clicked(self, event):
        if event.type == pygame.MOUSEBUTTONDOWN and event.button == 1:
            return self.rect.collidepoint(event.pos)
        return False
--------------------------------------------------------------------------------

Detailed Explanation:
- `class Button`: A blueprint object used to create interactive buttons on screen.
- `__init__`: Sets the button position $(x, y)$, width $(w)$, height $(h)$, label text, 
  value string, and color styles.
- `draw()`:
  - Gets the current mouse cursor position using `pygame.mouse.get_pos()`.
  - Checks if the cursor is hovering over the button (`collidepoint`).
  - Automatically brightens the button background when hovered to provide feedback.
  - Draws the button rectangle and centers the text label inside it.
- `is_clicked()`: Returns `True` if the left mouse button (button 1) is clicked 
  inside the button's rectangular area.

Detailed Explanation:
- `gx, gy, gw, gh`: Defines the graphical display region on screen (x=540, y=140, 
  width=480px, height=480px).
- `sp.lambdify(...)`: Converts SymPy's symbolic expression into a fast NumPy function 
  capable of processing arrays of values simultaneously.
- `np.linspace(...)`: Generates 400 evenly spaced numbers across the selected $x$-range.
- Window Bounds Logic: Safely calculates plotting boundaries ($x_{min}, x_{max}$), even if 
  integration limits are infinite ($-\infty$ to $\infty$), preventing program crashes.
- `to_pixel(mx, my)`: Coordinate Translator.
  - Translates mathematical coordinates $(x, y)$ into screen coordinates $(px, py)$.
  - Screen y-coordinates start at $0$ at the top of the window, so this function flips 
    the vertical axis so positive numbers go up.
- Area Shading: Calculates boundary vertices and uses `pygame.draw.polygon` with alpha 
  transparency to fill the region under $f(x)$ between $a$ and $b$.
- Indefinite Plotting: Plots both $f(x)$ in Cyan and its antiderivative $F(x)$ in Green.

PART 3: FREQUENTLY ASKED QUESTIONS (TEACHER Q&A)
--------------------------------------------------------------------------------

Q1: "How does Python solve symbolic integrals without hardcoded rules for every problem?"
A: Python uses SymPy, which implements algebraic algorithms such as the Risch 
   Algorithm alongside pattern-matching rules. It breaks down expressions into symbolic 
   tree structures and systematically computes antiderivatives mathematically.

Q2: "How does the app plot infinite limits on a finite computer monitor?"
A: The math engine computes exact improper integrals analytically using limits ($\lim$). 
   For graphic plotting, the rendering algorithm clips infinite boundaries to a 
   practical, high-clarity view window (e.g., $x \in [-10, 10]$) so curves display smoothly.

Q3: "Why build a UI with Pygame instead of standard window tools like Tkinter?"
A: Pygame provides direct control over pixel rendering, fast drawing loops, custom color 
   blending for graph transparency, and smooth interactive keypad button responses.
